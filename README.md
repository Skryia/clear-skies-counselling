# Clear Skies Counselling

I want you to create a modern, professional replacement website for an existing counselling and wellbeing website currently located at:

https://jenphillips85.wixsite.com/clearskies

The objective is to create a significantly improved version that could realistically be presented to the site owner as a replacement for their current website.

This is not a direct copy. Instead, analyse the existing site, understand its purpose, services, target audience, messaging, and user journey, then redesign it using modern UI/UX principles while preserving the overall brand identity and trustworthiness.

The organisation appears to provide counselling, wellbeing, therapeutic support, and related services. The new website should feel calm, professional, welcoming, trustworthy, and credible.

This project was built with [Lovable](https://lovable.dev).
